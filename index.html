Get Started GitHub

Cloud storage is convenient. It isn't private.

Traditional cloud storage leaves your data vulnerable to scanning, breaches, and third-party access.

They Hold The Keys

Cloud providers encrypt your data on their servers. They hold the decryption keys and can scan, analyze, or hand over your files at any time.

Decryption keys exposed on provider server

Centralized Breaches

When cloud servers are breached, your plaintext data is compromised. It creates a massive single point of failure.

Complex Tools

Heavy desktop installs and complicated key management are a thing of the past.

Security That Never Leaves Your Device

Advanced cryptography executed entirely within your browser.

100% Zero-Knowledge

We never see your password, keys, or files. Executed entirely on your local machine.

AES-256-GCM

Dynamic in-memory encryption that protects data confidentiality and instantly detects tampering.

Argon2id Key Derivation

Computational passphrase stretching that resists GPU attacks.

Native Cloud Integration

Direct OAuth integration with Google Drive and OneDrive without backend middleman servers.

Effortless Privacy in Three Steps

01

Lock

Set your master password. Encrypz derives your local keys using Argon2id in a background Web Worker.

02

Connect

Authenticate directly with your cloud provider via secure OAuth 2.0. No middleman involved.

03

Add Files

Drop files into the Encrypz app. Encrypz chunks and encrypts files locally before streaming directly to your storage.

How to Install on Debian, Ubuntu & Derivatives

Follow these three quick steps to install and run Encrypz on your Linux system:

1
Download Package

Download the .deb package using the button above. Open your terminal in your download folder.

cd ~/Downloads
2
Install via APT

Run APT to install the package and automatically resolve required system runtime libraries.

sudo apt install ./encrypz_1.0.0_amd64.deb
3
Launch Encrypz

Open Encrypz from your desktop Application Launcher, or execute from any terminal session.
